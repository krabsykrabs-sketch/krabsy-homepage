forecast – forecast – forecast

Inglés forecast = pronosticar, predecir

Forma basePasado simpleParticipio
forecastforecastforecast
3.ª persona (he/she/it): forecastsGerundio (-ing): forecasting

Frases de ejemplo con traducción

  • Pasado simpleThey forecast rain for the weekend.Pronosticaron lluvia para el fin de semana.
  • ParticipioExperts have forecast a difficult year.Los expertos han pronosticado un año difícil.
  • Pregunta (pasado simple)Did they forecast snow for Friday?¿Pronosticaron nieve para el viernes?
  • Negación (pasado simple)The weather report didn't forecast this storm.El parte meteorológico no pronosticó esta tormenta.
  • Presente (he/she/it)The app forecasts sunshine for the whole week.La aplicación pronostica sol para toda la semana.

Errores típicos

✗ Last week the app forecasts heavy rain.

✓ Last week the app forecast heavy rain.

El pasado de forecast es forecast también con he/she/it, sin -s; forecasts es presente.

✗ Did they forecasted rain for Saturday?

✓ Did they forecast rain for Saturday?

Después de did va siempre la forma base forecast, sin -ed, aunque hablemos del pasado.

Preguntas frecuentes

¿Cuál es el pasado de forecast?
El pasado (pasado simple) de forecast es forecast; el participio es forecast.
¿Cuál es el participio de forecast?
El participio (past participle) de forecast es forecast. Se usa después de have/has/had, por ejemplo en el present perfect: have forecast.
¿Cómo se dice forecast en pasado?
En pasado, forecast se dice forecast; con have/has se usa el participio forecast. Ejemplo: «They forecast rain for the weekend.» = «Pronosticaron lluvia para el fin de semana.» En preguntas y negaciones se usa did + forma base: did … forecast?, didn't forecast.
¿Cuál es el gerundio (forma -ing) de forecast?
forecasting: basta con añadir -ing (forecast → forecasting). En presente, con he/she/it se usa forecasts.
