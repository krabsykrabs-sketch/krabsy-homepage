arise – arose – arisen

Inglés arise = surgir, levantarse

Forma basePasado simpleParticipio
arisearosearisen
3.ª persona (he/she/it): arisesGerundio (-ing): arising

Frases de ejemplo con traducción

  • Pasado simpleA problem arose at the last minute.Surgió un problema en el último momento.
  • ParticipioSeveral questions have arisen from this.De esto han surgido varias preguntas.
  • Pregunta (pasado simple)When did the problem arise?¿Cuándo surgió el problema?
  • Negación (pasado simple)The problem didn't arise until the second game.El problema no surgió hasta el segundo partido.
  • Presente (he/she/it)A problem arises when the Wi-Fi is slow.Surge un problema cuando el wifi va lento.

Errores típicos

✗ Some questions have arose about the test.

✓ Some questions have arisen about the test.

Después de have/has/had va el participio arisen, no el pasado arose.

✗ A problem arised at school today.

✓ A problem arose at school today.

arise es irregular: «arised» no existe. Lo correcto es arose (pasado) y arisen (participio).

Preguntas frecuentes

¿Cuál es el pasado de arise?
El pasado (pasado simple) de arise es arose; el participio es arisen.
¿Cuál es el participio de arise?
El participio (past participle) de arise es arisen. Se usa después de have/has/had, por ejemplo en el present perfect: have arisen.
¿Cómo se dice arise en pasado?
En pasado, arise se dice arose; con have/has se usa el participio arisen. Ejemplo: «A problem arose at the last minute.» = «Surgió un problema en el último momento.» En preguntas y negaciones se usa did + forma base: did … arise?, didn't arise.
¿Cuál es el gerundio (forma -ing) de arise?
arising: se quita la e final (arise → arising). En presente, con he/she/it se usa arises.
