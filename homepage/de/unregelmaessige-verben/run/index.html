run – ran – run

Englisch run = laufen, rennen

GrundformSimple PastPast Participle
runranrun
3. Person (he/she/it): runs-ing-Form: running

Beispielsätze mit Übersetzung

  • Simple PastShe ran ten kilometres on Sunday.Sie ist am Sonntag zehn Kilometer gelaufen.
  • Past ParticipleHe has run this race before.Er ist dieses Rennen schon einmal gelaufen.
  • Frage (Simple Past)Why did the dog run away?Warum ist der Hund weggelaufen?
  • Verneinung (Simple Past)I didn't run fast enough to catch the bus.Ich bin nicht schnell genug gerannt, um den Bus zu erwischen.
  • Präsens (-ing-Form)My little brother is running around the garden.Mein kleiner Bruder rennt gerade durch den Garten.

Typische Fehler

✗ I run to school yesterday.

✓ I ran to school yesterday.

Ohne have/has steht das Simple Past ran. run brauchst du nur mit have/has: I have run.

✗ She has ran in three races.

✓ She has run in three races.

Nach have/has/had steht das Past Participle run – nicht das Simple Past ran.

Gut zu wissen: Typische Falle: „Ich bin zur Schule gelaufen“ (zu Fuß gegangen) heißt I walked to school. run bedeutet rennen, schnell laufen.

Häufige Fragen

Was ist das Simple Past von run?
Das Simple Past von run ist ran.
Wie lautet das Partizip (Past Participle) von run?
Das Past Participle (Partizip Perfekt) von run ist run. Du brauchst es nach have/has/had, z. B. im Present Perfect: have run.
Was ist die Vergangenheit von run?
Im Simple Past heißt run ran, im Present Perfect have/has run. Beispiel: „She ran ten kilometres on Sunday.“ – „Sie ist am Sonntag zehn Kilometer gelaufen.“ Fragen und Verneinungen bildest du mit did + Grundform: did … run?, didn't run.
Wie schreibt man die -ing-Form von run?
running – nach kurzem, betontem Vokal wird der letzte Konsonant verdoppelt: run → running. Bei he/she/it heißt es im Präsens runs.
