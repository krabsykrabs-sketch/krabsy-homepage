# Play-test of the weakest games, 2026-11-21

Subagent (Fable 5.2), headless Chromium with emulated touch:
- 1366×768 laptop
- 1024×768 touch tablet
- 390×844 phone

Local server only. No real devices were used, sound was not judged, and each
scenario was run once or twice. No console errors, 404s or failed requests
appeared in any game. Line numbers refer to `main` on 2026-11-21.

**Why these games:** median time on page (analytics May–Nov 2026, bots
removed, small samples):

| Game | Median time | People |
|---|---|---|
| Crab Slash | 0:18 | 16 |
| Verb Flow | 0:22 | 14 (mostly before the 2026-11-16 tutorial) |
| Verb Slash | 0:39 | 22 (mostly before the 2026-11-16 fix) |
| Air Control | 0:39 | 23 |
| Drag Match | 0:10 | 11 |
| Falling Forms | 0:12 | 10 |

For comparison: Verb Kitchen 1:39, Verb Snake 2:09.

## Verdicts

| Game | Verdict | Main reason |
|---|---|---|
| Drag Match | fix (small, <1 h) | Start button is below the fold on a laptop, the ✕ button throws the kid off the site, phones get a dead-end message. The game itself works. |
| Falling Forms | fix (small, <1 h) | Same page-layout problems. The game itself uses `know → ___ → ___` correctly. |
| Verb Slash | fix (small) | The correct ball is always green (then blue), so it can be played without reading. 5 s wait before the first action. English-only. |
| Crab Slash | **hide** | 8 of the 12 crabs carry correct forms of *other* verbs and count as wrong. No goal or stakes, English-only, unreadable on a phone. |
| Air Control | keep, fix (small) | Works everywhere and is well taught, but the ①②③ on each plane gives the answer away and labels are 6.5 px on a phone. |
| Verb Flow | keep as is | With the new tutorial it works on all three setups in both languages. Measure again before touching it. |

## If we only fix three things

1. **Drill page layout (fixes Drag Match and Falling Forms together).**
   - The iframe is a fixed 700 px and sits under the heading and intro card,
     so the start button is at page-y 727–796. A 1366×768 laptop shows
     about 650 px, so the kid sees text and a greyed-out board with no
     button.
   - In Falling Forms the block also falls past the fold, so a life is lost
     to a block the kid can't see.
   - Fix: put the game above the intro card and size the iframe to the
     viewport (`homepage/de/unregelmaessige-verben/drag-match/index.html:95`
     and `:124`, same lines in `falling-forms/index.html`, plus the ES
     pages).
   - Remove the ✕ button. It calls `history.back()` on the whole tab
     (`homepage/games/drag-match.html:1481`,
     `homepage/games/falling-forms-chain.html:1768`).
   - Under 900 px wide both drills are hidden behind "open on a wider
     screen". Link to a drill that works on a phone instead.
2. **Verb Slash: colour tell and slow start.**
   - Correct balls always get the `fruit-correct` class
     (`homepage/de/spiele/verb-slash/index.html:593`, CSS `:121–126`).
     Randomise colours.
   - Balloons take 5.1 s to arrive (`:787`).
   - A plain click or tap does nothing; only a 30 px swipe counts (`:448`).
   - An ignored ball costs a life after 4.6 s, and the right answer is
     never shown after a mistake.
   - All in-game text is English on both language pages.
3. **Hide Crab Slash.** Only the four crabs of the verb in the top panel
   count (`homepage/de/spiele/crab-slash/index.html:433`, `:600`, `:638`).
   With BUY as the prompt, slashing FORGOT or RAN gives the same red flash
   as BUYED. That is the game's central rule, so it needs a redesign, not a
   patch.

A fourth if there is time: **phone portrait.**
- Both slash games render as a 390×220 px strip with a 72×19 px start
  button.
- Air Control's labels are 6.5 px (`homepage/krabsy-air-control.html:1590`).
- Verb Kitchen and Verb Flow fill the phone screen.

## Other findings

- **Air Control timing:** level 1 took about 15 s and level 2 about 20 s,
  each ending on a "level complete" screen. That sum is close to the 0:39
  median, so people may leave at those screens. A play-test can't confirm
  that.
- **Air Control on phone:** with no input, level 3 ended in a crash after
  12 s. On the laptop there was no crash in 120 s. One run each.
- **Falling Forms:** a wrong answer never shows the correct one
  (`homepage/games/falling-forms-chain.html:1467`), so a guessing beginner
  is out in about 20 s.
- **Language rule:** no game *asks* in grammar terms.
  - Both slash games say "simple past and past participle" in their English
    start-screen sentence.
  - Drag Match uses those terms as stage label, column heading and slot
    placeholder, which is borderline.
- **Spanish:** Verb Flow, Air Control and both drills are translated. Crab
  Slash and Verb Slash are fully English in-game.
- **Verb Kitchen comparison:** it fills the screen on every device, shows
  the goal as a picture, has a level grid with stars, and keeps verbs as a
  low-pressure side-task. The live build is English-only too, so language
  alone doesn't explain the gap.
- **Crab Slash frame rate:** its loop advances once per screen refresh
  (`:678`), so crabs move twice as fast on a 120 Hz screen. Verb Slash's
  fixed-rate fix holds on start and restart.
